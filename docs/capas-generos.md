# Capas de gêneros

## Origem e tratamento

As capas preto e branco foram copiadas das artes-base da pasta images/genres/silhouettes do projeto público [tolbertsol/nuvio](https://github.com/tolbertsol/nuvio/tree/main/images/genres/silhouettes). Imagegen foi usado para substituir os rótulos em inglês, mantendo o fundo, a textura diagonal, o contraste e o enquadramento panorâmico. A capa crime.png foi copiada sem edição porque CRIME já é o mesmo rótulo em pt-BR.

| Capa | Origem | Rótulo |
|---|---|---|
| acao.png | action-base.png | ACTION → AÇÃO |
| fantasia.png | fantasy-base.png | FANTASY → FANTASIA |
| ficcao-cientifica.png | sci-fi-base.png | SCI-FI → FICÇÃO CIENTÍFICA |
| terror.png | horror-base.png | HORROR → TERROR |
| animacao.png | animation-base.png | ANIMATION → ANIMAÇÃO |
| crime.png | cime-base.png | CRIME, sem alteração |
| comedia.png | comedy-base.png | COMEDY → COMÉDIA |
| historia.png | history-base.png | HISTORY → HISTÓRIA |
| documentario.png | documentary-base.png | DOCUMENTARY → DOCUMENTÁRIO |
| faroeste.png | western-base.png | WESTERN → FAROESTE |
| suspense.png | criação nova com a mesma linguagem visual | SUSPENSE |

As imagens são servidas pelo GitHub Raw em assets/covers/generos/. As capas das décadas em assets/covers/decadas/ são SVGs panorâmicos e autossuficientes.
