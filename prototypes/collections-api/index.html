Uma coleção, duas versões.

Esta prova verifica se a API do Nuvio permite criar a coleção A, trocar seu filme e voltar à versão anterior, preservando as demais coleções do perfil.

Como conferir a troca

  1. Prepare e aplique v1. Abra A - v1 no Nuvio e confira Madrugada dos Mortos.
  2. Prepare e aplique v2. Após sincronizar o app, a mesma coleção vira A - v2, com O Rei Leão.
  3. Aplique v1 novamente para conferir a reversão.

Cada aplicação salva um backup local e confirma a resposta por uma nova leitura da API. O addon do protótipo é instalado na primeira aplicação. O tempo de sincronização depende do aplicativo.
